# महा पासपोर्ट: विभागांकडून आवश्यक माहितीचे स्वरूप

**Pilot साठी डेटा मागणी पत्रासोबत जोडण्यासाठी परिशिष्ट (मसुदा)**

## सर्वसाधारण सूचना

1. फाईल **Excel (.xlsx) किंवा CSV** स्वरूपात द्यावी. एका फाईलमध्ये जास्तीत जास्त 2,00,000 ओळी.
2. पहिल्या ओळीत column ची नावे असावीत. नावे **मराठी किंवा इंग्रजी** कोणत्याही भाषेत चालतील.
3. दिनांक **दिवस-महिना-वर्ष** (उदा. 05-03-2026) किंवा वर्ष-महिना-दिवस (2026-03-05) स्वरूपात.
4. पत्ता शक्य तितका पूर्ण असावा: **घर / गाळा क्रमांक, रस्ता, परिसर / भाग, प्रभाग**. पत्ता पूर्ण असेल तर जुळवणी अचूक होते.
5. नमुना फाईल प्रत्येक विभागासाठी प्रणालीमध्ये (विभागांचा data → नमुना file) उपलब्ध आहे.
6. सर्व माहिती फक्त मालमत्ता कर आकारणीतील उणिवा शोधण्यासाठी वापरली जाईल. माहिती भारतातील शासकीय मान्यताप्राप्त server वर साठवली जाईल, आणि प्रत्येक वापराची नोंद audit log मध्ये राहील (डिजिटल वैयक्तिक माहिती संरक्षण अधिनियम, 2023 नुसार).

`*` = अनिवार्य
